# User guide

## First run

1. Open **Pengaturan**, choose a provider and model, paste your API key, and
   press **Tes koneksi**.
2. Open **Validasi Baru** and upload the WBS. The page confirms how many leaf
   items it found and the period.
3. Upload the request document and, if you have one, a supporting document
   such as meeting notes.
4. Check the scope and the period. Write any context the documents do not
   state, for example that the project actually runs for two months.
5. Press **Jalankan validasi** and follow the agents in **Proses**.

## Reading the result

- **Ringkasan FTE** shows, per role, the FTE from both methods, the request,
  existing talent, and the additional need. The conclusion compares the
  additional need with the request.
- Rows marked **Perlu review** deserve a look before the result is used.
- Change a row in **Breakdown WBS** and every number is recalculated. To let
  the agent decide again, select rows, write a comment, and press
  **Nilai ulang dengan agent**.
- **Peluang Bantuan AI** is a scenario. It does not change the baseline.

## Settings worth knowing

- **Talent existing** turns the total need into the additional need.
- **PHM** scales the UCP method. Change it only with evidence.
- **Katalog Capability** can be replaced for the session with your own file.

## Privacy

Nothing is stored on the server. The result lives in the tab; download the
workbook before closing it.
