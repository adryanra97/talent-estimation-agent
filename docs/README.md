# Documentation

The documents follow the phases of the Unified Process used in Dennis, Wixom,
and Tegarden, *Systems Analysis and Design: An Object-Oriented Approach with
UML* (5th ed.). Diagrams are written in Mermaid so they render on GitHub and
change together with the code.

| | [Workplan](01-planning/workplan.md) | Phases, iterations, schedule |
| Analysis | [Requirements](02-analysis/requirements.md) | Functional and nonfunctional requirements, user stories |
